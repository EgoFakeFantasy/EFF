## 未宣称完成

本轮不交付 Rust/Wasm 动态规则、引擎自演化或 GPU/内存自动选档；模型只在合法候选中规划。不将单台硬件的有限测量推广为所有模型质量或最低配置保证；不宣称 Node VM 能提供 OS 隔离，也不宣称设备所有者不能篡改程序。

## 可复用经验

1. 旧工作树有未提交美术、远端又加入过场和音乐时，从最新远端建立独立工作树，三方合并并先跑原回归；不要 reset 原目录或只按旧提案接口编码。
2. 双侧必须观察同一 revision，在一次仲裁事务里解决冲突；过期提案不消耗新回合。预算导致占据时，当前 bodyOwner 也必须转换，不能只写坏结局名称。
3. 离线桌面不等于开一个 localhost 网页。原生宿主用受限资源协议与 preload，实际文件存档和进程退出另验；Node VM 只用于剧情测试。
