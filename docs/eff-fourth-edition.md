# 第四版 · 现象战争（v0.6.0）

[浏览器预览](https://egofakefantasy.github.io/EFF/local-version/) · [Windows 便携包](https://github.com/EgoFakeFantasy/EFF/releases/tag/v0.6.0)

第四版以像素箱庭为舞台，将现象争夺映射到同一个可操控的世界。两个代理各自规划，确定性仲裁确认回应，然后画面、输入、碰撞和检查点一起接续。

## 演出如何作用于玩法

| 争夺对象 | 画面 | 实际作用 |
| --- | --- | --- |
| 身体 | 外来者的牵引脉冲，断线回缩，人物带血的衣着与关节显露 | 回应成立后，玩家输入才控制人物；尚未成立时由牵引决定运动 |
| 指认 | 指向身体的归责链、被划去并剥离的标签 | 单独校验指认是否已拒绝，获得身体不自动消除指认 |
| 结局 | 庭院周围的封印与刺点，BAD END 印记裂成两半 | 结局的碰撞边界只在该回应成立后打开；三项全成立才接续下一实例 |
| 发生的过程 | 全窗口原句与替代句交锋，现有界面裂成不规则碎片 | 正文和改写前的文字同时保留，可暂停并滚动阅读 |
| 获请求后的过去 | 同一条历史向过去延伸，逆向移动的插入光点 | 未获原文请求时不存在可用的过去锚点，也不显示协助者的介入 |
| 运行实例 | 碎片脱落、黑场、相同程序表面重新显现 | Windows 的旧世界子进程退出后才生成下一世界；位置与合法检查点保留 |

外来者失守与玩家被占据采用不同的收束。被占据的演出保留压迫的运行表面，不能冒充玩家成功重建。减少动态使用静态回应，仍执行必要的合法重建；暂停、失焦、阅读工具会停下世界时间。

## 美术与渲染

保留原像素演员、尸体、血迹、庭院残骸与区域特效。所有层以同一相机和整数像素绘制，场景保持宽高比。运行骨架只暴露真实障碍物轮廓、关节与控制连接，不用全场网格遮住场景。全窗口裂片以争夺对象为中心，执行轨迹只在裂边显露少量真实记录。

地图材质和障碍轮廓缓存，动态像素层与运行骨架使用两张固定尺寸的 GPU 纹理，每帧更新内容而不重新分配纹理。WebGL2 不可用或上下文丢失时，Canvas 使用同一个状态继续绘制和操作。

## 范围

第四版复用完整原文之旅、九种结局及原有互动。技术争夺拥有独立存档，练习与演出预览不修改主线。原文庭院仍须逐项说完拒绝段；终章原句和说话者的数据文件未改动。

浏览器预览运行同一套世界规则；Windows 版增加文件存档、本地模型连接和真实世界子进程。没有嵌入第三方商业游戏，也没有任意执行模型生成的程序：双代理只提交有限数据式方案。模型默认关闭，已有本地权重由玩家自行配置；无模型可完整游玩。

运行架构见[动态世界](./eff-live-world.md)，模型协议见[本地 AI](./eff-local-ai.md)，验收方法与边界见[验证说明](./eff-local-verification.md)。
