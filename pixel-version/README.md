# 无中归来者 · 箱庭版（pixel-version）

在原版网页 AVG 与 new-version 之外建立的**区域探索箱庭像素版**原型。原版、new-version 均未改动；本版本使用独立存档键：

- 周目进度：`wuzhong-returner-pixel-v1`
- 跨周目图鉴（记忆碎片 / 已抵达结局）：`wuzhong-returner-pixel-meta-v1`

## 玩法

- 方向键 / WASD 移动，Shift 快走；E / 空格 / Enter 互动与推进对话（点击对话框或下方操作按钮也可推进）。互动键长按不会跳过对白。
- 手机可按住下方方向键移动，用「调查 / 继续」阅读；小屏长对白与结局可滚动。
- 八个箱庭区域：镜像回廊 → 无尽圆塔（暴雨）→ 棺之花园 → 空屋 → 家 · 日常 → 血色庭院 → 雨塔 · 心象 → 终章 · 话语表面。
- 剧情文本沿用原版原文；选择与坏结局由「空间中的行动顺序」触发：
  - 没调查洗衣机就打开马桶水箱 → BAD END 00；
  - 在记忆的暗处强行追溯三次 → BAD END 03；
  - 血色庭院接受罪责 / 逃走 → BAD END 01 / 02；
  - 雨塔中选择「追问记忆为什么在流失」（手心里的雨水）并在终章接住坠落的金色雨滴 → 真结局「无垠之萍」；否则为 Normal Ending。
- 每个区域藏有一枚记忆碎片（共 8 枚），跨周目保留在图鉴中。第二幕读完入场对白后，可略微向右偏移触及雨中的碎片，再伸手推进；错过后可在重玩时收集。
- 偏头痛压力条：强行追溯与水箱事件会累积头痛，HUD 常驻显示，发作时红闪。
- 同行者的回声位：条件满足后，各区域出现半透明的残影 NPC（旅伴 / 棺中住客 / 妹妹），触发基于原文的回声对话并点亮对应记忆。
- 重玩保留碎片与结局图鉴。同行者回声只引用原版对应场景的原句；不再添加二周目剧情事实。终章已有的碑文覆盖演出保留。
- **第二幕从入场即向天空红月逆落**：镜头随同一个身体向上，塔层持续向下掠过，雨滴仍按原文向下流。补回原文「掉出无尽螺旋的回廊」一句；入场对白自然开始，按互动键或「伸手」留住雨滴，脚步、抬头、黑影与告别按原文顺序呈现，读完后在花园醒来。没有地面寻路、月旁调查点或出口门槛；左右操作只略微调整空中位置。减少动态时保留静态雨幕和相应姿态，流程照常。
- 每个区域有与文本对应的标志性演出：镜中的倒影（读过的镜子会裂开）、花园的流萤与世界边界雾缘与棺文微光、空屋的斜窗光与灯光闪烁与仍在震动的洗衣机、日常之家的电视闪光与厨房蒸汽、血色庭院的余火与心跳边缘、心象水潭的涟漪与闪电、终章漂浮的字符与亮起的石碑。
- 音景为浏览器本地程序化生成（Web Audio），随区域切换，默认关闭，右上角开启。

## 本轮体验优化

- 04/05 的入场醒来自动在卧室播放；空客厅和另一卧室、卫生间镜子与洗衣机、触痛后在棺内醒来，都有对应的镜头和姿态。逐句演出提示保存在剧本数据中，跨世界对白保持完整存档事务。
- 日常之家先见沙发上看新闻的父亲，再看母亲端菜穿门进入客厅；电视关闭后一家人坐到桌边，三碗白粥和配菜可见。「慢慢喝」移回就餐段。父母上班后离场，三日和第四日幕间按原文衔接；再次过塔与幕间使用独立背景。
- 血色庭院入场即呈现受束缚的主角，脸、手、衣裤有溅血，心脏与主角的手相连，妹妹倒在眼前。随后穿门进入褐色客房，看清相拥残骸后再次受缚并自然进入审判。离开血色世界后不再显示这组血迹与持物；旧存档仍可续接。
- 八个区域各有原文关键句的章节入场；对白按照旁白、引用、破碎话语与碑文改写切换视觉颜色。拒绝段的雪花与红灰碰撞对应原文描写，血色庭院可见手与心脏及相拥的焦炭。
- 下方显示当前探索方向，画面边缘提示目标所在方位；提示可以在设置关闭。「区域地图」显示你、调查点、已经出现的同行者、碎片与出口。
- 金雨先给出落点预告，在三条可达的路线落下；光圈与上方金光始终提示位置，错过后可重试。对话、图鉴、设置、回读和页面失焦时暂停收集；不增加新的结局条件。
- 「回读」只记录本周目已呈现的对白，不改变分支或重发奖励。「设置」可调整文字速度、音量、探索提示和减少动态与闪光，关闭环境运动后仍能接金雨。
- 周目与图鉴独立校验、读取；旧 v1 存档继续兼容。每三秒在稳定探索状态保存位置，完整对白/选择/转场后保存检查点。中途刷新从上一个完整检查点重播未结束的对白，已抵达的结局可恢复；重启取消旧对白与转场回调。
- 运行逻辑与额外演出分别位于 `game.js` 和 `enhancements.js`；`storm-flight.js` 负责第二幕专属逆落镜头，`story-staging.js` 负责逐句镜头、人物姿态与过场背景。动态瓦片在进入区域时建立索引，逐字文本只在内容变化时更新 DOM。

设置与回读的独立键为 `wuzhong-returner-pixel-settings-v1`、`wuzhong-returner-pixel-journal-v1`。所有存档都在当前浏览器本地；重启会清除本周目回读，保留设置与图鉴。

## 运行

纯静态网页，直接打开 `index.html` 即可；开发测试可在本目录启动任意静态 HTTP 服务器。

从仓库根目录执行 `node tests/pixel-regression.cjs` 可运行无外部依赖的流程回归测试。测试使用 Node VM 与 DOM/Canvas 模拟，覆盖六结局真实互动、存档与刷新、地图可达性及操作边界；视觉与原生浏览器交互另行人工检查。

## 与原版的关系

- 不重写、不覆盖原版任何文件与存档。
- 原版 SVG 场景图未被本版本使用：画面全部由 Canvas 程序化像素绘制（ tiles、角色、粒子、红月、水晶花），无外部素材依赖。
