# 无中归来者 · 箱庭版（pixel-version）

在原版网页 AVG 与 new-version 之外建立的**区域探索箱庭像素版**原型。原版、new-version 均未改动；本版本使用独立存档键：

- 周目进度：`wuzhong-returner-pixel-v1`
- 跨周目图鉴（记忆碎片 / 已抵达结局）：`wuzhong-returner-pixel-meta-v1`

## 玩法

- 方向键 / WASD 移动，E / 空格 / Enter 互动与推进对话（点击对话框也可推进）。
- 八个箱庭区域：镜像回廊 → 无尽圆塔（暴雨）→ 棺之花园 → 空屋 → 家 · 日常 → 血色庭院 → 雨塔 · 心象 → 终章 · 话语表面。
- 剧情文本沿用原版原文；选择与坏结局由「空间中的行动顺序」触发：
  - 没调查洗衣机就打开马桶水箱 → BAD END 00；
  - 在记忆的暗处强行追溯三次 → BAD END 03；
  - 血色庭院接受罪责 / 逃走 → BAD END 01 / 02；
  - 雨塔中选择「追问记忆为什么在流失」（手心里的雨水）并在终章接住坠落的金色雨滴 → 真结局「无垠之萍」；否则为 Normal Ending。
- 每个区域藏有一枚记忆碎片（共 8 枚），跨周目保留在图鉴中。
- 偏头痛压力条：强行追溯与水箱事件会累积头痛，HUD 常驻显示，发作时红闪。
- 同行者的回声位：条件满足后，各区域出现半透明的残影 NPC（旅伴 / 棺中住客 / 妹妹），触发基于原文的回声对话并点亮对应记忆。
- NG+ 回读改写：抵达过任一结局后重开，镜像、花园苏醒、棺底铭文等场景出现局部文本改写。
- **第二幕高塔是「逆落」演出**：回廊在三条镂空带之间攀升，带外是两层视差的无穷塔层——揭示前塔层向上流过（人在下坠的错觉）；在红月下听完那句话之后，塔层反向、雨改从地面向红月落去，浑黑的人影违反物理法则向塔顶红月「落去」。
- 每个区域有与文本对应的标志性演出：镜中的倒影（读过的镜子会裂开）、花园的流萤与世界边界雾缘与棺文微光、空屋的斜窗光与灯光闪烁与仍在震动的洗衣机、日常之家的电视闪光与厨房蒸汽、血色庭院的余火与心跳边缘、心象水潭的涟漪与闪电、终章漂浮的字符与亮起的石碑。
- 音景为浏览器本地程序化生成（Web Audio），随区域切换，默认关闭，右上角开启。

## 运行

纯静态网页，直接打开 `index.html` 即可；开发测试可在本目录启动任意静态 HTTP 服务器。

## 与原版的关系

- 不重写、不覆盖原版任何文件与存档。
- 原版 SVG 场景图未被本版本使用：画面全部由 Canvas 程序化像素绘制（ tiles、角色、粒子、红月、水晶花），无外部素材依赖。
