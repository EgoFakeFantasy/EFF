# 无中归来者 · 新版本

这是在原版网页 AVG 之外建立的独立新版本原型。原版仓库和远端文件不由本目录覆盖；本版本使用独立的 `localStorage` 存档键 `wuzhong-returner-new-v2`。

带有 `?test=名称` 参数的本地链接使用按名称分离的测试进度，不会覆盖正常游玩存档。

## 当前垂直切片

- 保留网页 AVG 的逐句阅读和原文选择形式。
- 首次抵达结局后，可以回读已经走过的故事。
- 回读会让 `他者的要求` 场景出现局部文本改写。
- “声音在听清以前离去”和“手心里仍然留下了一滴”都被抵达并保留后，才会在终局中互相覆盖、争夺留下的位置。
- 终局从结尾向回走，雨水会在限定时间内从上方向下落；普通雨水累计分数，四滴金色雨水回收关键记忆。
- 雨水阶段持续 18 秒，并分别出现在无尽螺旋高塔的坠落段与黄昏接雨段。普通雨水有接住/漏过统计和连击；连续接住会提高单滴得分，金色雨滴按剧情段落出现，错过后会在后续段落再次出现。
- 运算战持续 18 秒。时间会把故事推向黄昏，点击任一要素会使它下沉，并把强度交给另一方；同一方向连续介入会增加当前点击重量，实时平衡条显示两种结尾的覆盖关系。
- 对抗双方会以“正在取得位置”或“被压回句子里”的短句、强度条和压力边线同时反馈当前局势；玩家不需要只盯着数字判断该压低哪一边。
- 运算战有一个很轻的周期节拍：节拍带进入亮区时点击当前正在上升的要素，会获得额外重量并留下节拍连击；错过节拍仍可继续介入，不会把阅读流程变成音游。
- 场景图上有随场景变化的雨丝、呼吸和镜面层；雨水阶段增加了可见的“手心”落点，接住普通雨水、关键雨水和连续雨水会留下不同的光迹。
- 侧栏的四滴记忆路线会逐滴点亮，显示“被呼喊的名字”“手心里的雨水”“听清以前离去的声音”“尚未写完的明天”是否已经留下。
- 普通雨水越多，每次介入的幅度越大。四滴关键雨水全部回收后，第二次起的最后阶段会出现“抓住仍在下落的雨”：持续介入、维持两种坏结局的空隙后抓住它，才会抵达真结局。
- 第一次运算战必然落入黄昏；第二次起，持续介入可抵达“承认乌有的罪孽”。两次“同行者”都被点击后，只会把原本通往黄昏的路径转入无意识主体，不会覆盖“承认乌有的罪孽”或已经开启的真结局。
- 点击“同行者”会展开对应的回声位；当前以省略号留白，便于之后依据原文补入专属对话。

## 运行

这是纯静态网页，直接打开 `index.html` 即可；开发测试也可以在本目录启动任意静态 HTTP 服务器。
