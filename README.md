# 无中归来者

《无中归来者》是一款改编自 SF 小说网《混沌树海》周防篇、以原文叙事为核心的网页游戏。当前主要开发版本为 **第四版 · 现象战争（local-version，v0.6.0）**，以像素箱庭版为基础，增加本地双代理、可操控的运行世界与全窗口现象演出。像素箱庭版通过区域探索、人物对话、记忆收集与直接作用于文字和现象的互动，呈现周防的经历。

**[进入第四版](https://egofakefantasy.github.io/EFF/local-version/)** · **[下载 Windows 本地版](https://github.com/EgoFakeFantasy/EFF/releases/tag/v0.6.0)** · [在线游玩像素箱庭版](https://egofakefantasy.github.io/EFF/pixel-version/) · [箱庭版详细说明（含剧透）](./pixel-version/README.md)

## 像素箱庭版体验

- 八个章节场景、八枚可跨周目保留的记忆碎片，以及九种结局。调查顺序与剧情选择会影响进程。
- Canvas 像素场景与人物头像，包括分层材质、家具细节、场景光影，以及与正文同步的人物姿态和镜头切换；以设备像素整数倍缩放并对齐相机像素，增强颗粒清晰度。
- 根据小说正文校正说话者与问答顺序，补回镜像阶段的推理及庭院的松手动作；新增木面、空床铺、水潭、裂隙调查，点击对象可标记或在近处调查。
- 暴雨圆塔中向天空的红月逆落；日常场景随人物行动转换地点；血色庭院以身体血迹和侵入全屏的话语呈现夺权压力。
- 战斗围绕身体所有权、表象和过程的改写展开。玩家选择回应对象、比较被覆盖的文字，并在剧情允许时回到过去介入事件。
- 新增作者指定的改编机制：日常停留的概率锁定、庭院限时反抗，以及黄昏之海接雨水。三条失败分支各有独立结局，暂停与检查点同时覆盖这些操作。
- 终章保留完整原文节点，以回溯插入、故事覆盖、前传回声和整章回写承载操作，而不是将正文压缩为探索提示。
- 像素光影：各区域有自己的光源（镜面、棺木铭文、窗光、电视、厨房、余火、红月、水潭），阴影以有序抖动量化在整数像素上；尚未调查的事物会微微发光，读过后归于安静。人物有四帧步行、侧面轮廓、摆臂与眨眼，地面有裂纹、磨损、污渍与镶嵌等变化，脚步在雨地溅起水花。
- 剧情转折处的像素演出：离开镜像回廊时画面碎裂坠落、躺入棺材时棺盖合上并收成一道缝、在床上醒来时睁眼眨动并弹起、血色庭院先在原地裂开并闪过雪花纹，再随「场地不断下落」碎成泡沫与无色的雨水；母亲端菜时也会迈步行走。
- 程序化音乐：每个区域一段 Web Audio 即时合成的主题（镜廊的清冷琴音、花园的八音盒、空屋稀疏的不协和音、家中的暖和弦、庭院的心跳、雨塔的小调琶音、终章的五度上行，真结局与坏结局各有收尾），以及镜碎、棺盖、醒来、庭院崩裂与坍落、拾取碎片的音效。随「音景」开关，设置中可单独关闭背景音乐。
- 九种结局各有一张依据结局正文绘制的像素插图，例如 BAD END 04 是黄昏中的早餐桌与窗外的海，真结局「无垠之萍」是浮萍水面上留住一滴雨水的手。
- 调查标记区分「未调查 / 尚未开启 / 已调查」，探索栏与地图显示本区调查进度；靠近未拾取的记忆碎片时，碎片发光、闪烁并以渐高的音色共鸣。
- 对白可开启「自动」，或用「快进已读」/ 按住 Ctrl 跳过任何周目读过的句子；遇到未读句子、选择、现象写入、挑战与终章的可点击回答时停下。
- 提供回读、记忆图鉴、区域地图、探索提示、文字速度、音量、减少动态与闪光、光影与暗角设置。程序化音景默认关闭，可手动开启（含按地面材质变化的脚步声）。

演出与玩法以原文含义、说话者身份和事件顺序为依据。具体剧情机制与结局条件见[箱庭版说明](./pixel-version/README.md)。

## 操作与存档

| 操作 | 方式 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 快走 | Shift |
| 调查、推进对白 | E / 空格 / Enter，或点击对白与操作按钮 |
| 触屏游玩 | 按住屏幕下方方向键，点击「调查 / 继续」 |
| 自动 / 快进已读 | 对白框右下角的「自动」「快进已读」，或按住 Ctrl 快进已读 |
| 现象争夺 | 点击目标，或左右方向键选择、E 确认 |

逆落、过场和终章会使用各自的操作方式，请留意当前提示。

存档保存在当前浏览器的本地存储中，不会跨设备同步。更换浏览器、访问地址或端口时，可能读不到原来的存档。箱庭版在稳定探索时保存位置，在完整对白、选择和转场后保存检查点；概率结果、反抗剩余时间及接雨进度，以及身体重组、自我编排、回写调查和研究院尾声另外保存可恢复的操作检查点，刷新不会重新抽签或重置整个限时；中途刷新可能重播尚未完成的一段对白。重启保留设置、碎片与结局图鉴，清除本周目回读。

## 本地运行

项目为纯静态 HTML / CSS / JavaScript，无需安装前端依赖或执行构建。可以直接打开对应版本的 `index.html`；开发时建议从仓库根目录启动静态服务器，例如安装 Python 后执行：

```sh
python -m http.server 4179
```

随后访问 `http://localhost:4179/pixel-version/`。持续使用同一地址和端口，便于保留本地存档。

## 部署

`main` 已包含当前箱庭版。推送到 `main` 后，GitHub Actions 的 `Deploy static game to GitHub Pages` 工作流发布仓库根目录；也可手动触发。四个版本分别保留各自路径。

部署到其他静态托管服务时，上传完整仓库站点文件并保留目录结构即可。


## 第四版 v0.6.0：双代理现象战争

新增独立入口 [local-version](./local-version/README.md) 与 Electron Windows 宿主，复用当前箱庭剧情、美术、过场和音乐。普通模式保持原九种结局；技术模式增加数据式规则编辑、本地模型双代理提案、确定性仲裁与事件重放。守护侧与外来者共享一套本地权重、分别规划，玩家审阅后才执行；模型关闭或单侧失败时分别回退规则模板。默认离线、无模型也可游玩。

实现框架、叙事边界和后续阶段见[本地版技术文档](./docs/eff-local-implementation.md)。双代理接口与实际模型验收见[本地 AI 说明](./docs/eff-local-ai.md)。此新增入口不改变网站根目录的原版入口。

0.4 增加[全窗口现象演出](./docs/eff-screen-spectacle.md)：窗口撕裂、执行轨迹显露、视觉崩溃与虚拟运行实例重建，并在终章呈现原句覆盖与获授权的过去回写。主菜单可直接预览。

0.5 增加[动态世界与原生实例](./docs/eff-live-world.md)：血色庭院的身体输入、结局碰撞边界、归责链与终章过去锚点由同一状态驱动；WebGL2 统一合成像素场景和运行骨架，重建实际切换世界子进程。

第四版精修三种回应的画面：身体牵引回缩并断开，强加的指认剥离，结局封印裂解。运行层只显露实际碰撞轮廓与控制连接；全窗口碎片随争夺对象变化。终章保留完整原句和替代句，授权后的回溯沿同一条历史呈现。重建画面等待原生世界的成功回执，身体位置与已确认的回应接续。

浏览器可预览剧情、规则争夺和视觉演出，使用同一世界规则的浏览器实例；Windows 程序另有文件存档、本地模型连接及实际世界子进程的退出／生成。模型权重需由玩家自行准备，默认关闭，无模型时可用规则模板完整游玩。演出可暂停、略过，并支持减少动态。

第四版的演出与实际操控关系见[第四版说明](./docs/eff-fourth-edition.md)。
