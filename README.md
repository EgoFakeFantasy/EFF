# 无中归来者

《无中归来者》是一款改编自 SF 小说网《混沌树海》周防篇、以原文叙事为核心的网页游戏。当前主要开发版本为 **像素箱庭版（pixel-version）**：通过区域探索、人物对话、记忆收集与直接作用于文字和现象的互动，呈现周防的经历。

**[在线游玩像素箱庭版](https://egofakefantasy.github.io/EFF/pixel-version/)** · [箱庭版详细说明（含剧透）](./pixel-version/README.md)

## 版本与入口

仓库保留三个版本，存档互相独立：

| 版本 | 内容 | 在线入口 | 本地入口 |
| --- | --- | --- | --- |
| 像素箱庭版（当前主要版本） | 区域探索、像素人物与场景、分场演出、现象与过程争夺 | [开始游戏](https://egofakefantasy.github.io/EFF/pixel-version/) | `pixel-version/index.html` |
| 文字演出版 | 文字演出与雨水玩法 | [文字演出版](https://egofakefantasy.github.io/EFF/new-version/) | `new-version/index.html` |
| 原版 | 原始文字网页游戏 | [原版](https://egofakefantasy.github.io/EFF/) | `index.html` |

**网站根地址仍然进入原版文字游戏。** 最新箱庭版的地址包含 `/pixel-version/`；合并到 `main` 不会自动改变首页入口。

## 像素箱庭版体验

- 八个章节场景、八枚可跨周目保留的记忆碎片，以及九种结局。调查顺序与剧情选择会影响进程。
- Canvas 像素场景与人物头像，包括分层材质、家具细节、场景光影，以及与正文同步的人物姿态和镜头切换；以设备像素整数倍缩放并对齐相机像素，增强颗粒清晰度。
- 根据小说正文校正说话者与问答顺序，补回镜像阶段的推理及庭院的松手动作；新增木面、空床铺、水潭、裂隙调查，点击对象可标记或在近处调查。
- 暴雨圆塔中向天空的红月逆落；日常场景随人物行动转换地点；血色庭院以身体血迹和侵入全屏的话语呈现夺权压力。
- 战斗围绕身体所有权、表象和过程的改写展开。玩家选择回应对象、比较被覆盖的文字，并在剧情允许时回到过去介入事件。
- 新增作者指定的改编机制：日常停留的概率锁定、庭院限时反抗，以及黄昏之海接雨水。三条失败分支各有独立结局，暂停与检查点同时覆盖这些操作。
- 终章保留完整原文节点，以回溯插入、故事覆盖、前传回声和整章回写承载操作，而不是将正文压缩为探索提示。
- 提供回读、记忆图鉴、区域地图、探索提示、文字速度、音量及减少动态与闪光设置。程序化音景默认关闭，可手动开启。

演出与玩法以原文含义、说话者身份和事件顺序为依据。具体剧情机制与结局条件见[箱庭版说明](./pixel-version/README.md)。

## 操作与存档

| 操作 | 方式 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 快走 | Shift |
| 调查、推进对白 | E / 空格 / Enter，或点击对白与操作按钮 |
| 触屏游玩 | 按住屏幕下方方向键，点击「调查 / 继续」 |
| 现象争夺 | 点击目标，或左右方向键选择、E 确认 |

逆落、过场和终章会使用各自的操作方式，请留意当前提示。

存档保存在当前浏览器的本地存储中，不会跨设备同步。更换浏览器、访问地址或端口时，可能读不到原来的存档。箱庭版在稳定探索时保存位置，在完整对白、选择和转场后保存检查点；概率结果、反抗剩余时间及接雨进度另外保存可恢复的挑战检查点，刷新不会重新抽签或重置整个限时；中途刷新可能重播尚未完成的一段对白。重启保留设置、碎片与结局图鉴，清除本周目回读。

## 本地运行

项目为纯静态 HTML / CSS / JavaScript，无需安装前端依赖或执行构建。可以直接打开对应版本的 `index.html`；开发时建议从仓库根目录启动静态服务器，例如安装 Python 后执行：

```sh
python -m http.server 4179
```

随后访问 `http://localhost:4179/pixel-version/`。持续使用同一地址和端口，便于保留本地存档。

## 代码与验证

| 路径 | 职责 |
| --- | --- |
| `pixel-version/game.js` | 探索、剧情流程、互动与存档 |
| `pixel-version/enhancements.js` | 回读、地图、设置等体验功能 |
| `pixel-version/storm-flight.js` | 暴雨圆塔逆落演出 |
| `pixel-version/story-staging.js` | 逐句镜头、人物姿态与场景调度 |
| `pixel-version/combat-script.js` | 庭院战斗与心象雨塔原文数据 |
| `pixel-version/finale-script.js`、`finale.js` | 完整终章数据、文字演出与结局操作 |
| `pixel-version/phenomenon-battle.js` | 现象争夺、过去锚点与过程改写 |
| `pixel-version/narrative-trials.js` | 家庭停留概率、庭院反抗时间、黄昏接雨与对应检查点 |
| `pixel-version/pixel-art.js` | 像素头像、材质和舞台绘制 |
| `tests/pixel-regression.cjs` | 箱庭版流程回归测试 |

安装 Node.js 后，从仓库根目录运行：

```sh
node tests/pixel-regression.cjs
```

回归测试使用 Node VM 与模拟 DOM / Canvas，检查剧情互动、结局、存档和操作边界；它不能替代真实浏览器中的视觉、音频与触屏体验检查。GitHub Actions 的 `Check pixel game` 工作流负责自动检查。

## 部署

`main` 已包含当前箱庭版。推送到 `main` 后，GitHub Actions 的 `Deploy static game to GitHub Pages` 工作流发布仓库根目录；也可手动触发。三个版本分别保留各自路径。

部署到其他静态托管服务时，上传完整仓库站点文件并保留目录结构即可。
